# XRay_MSU

Расчёт интенсивностей рентгеновской (или монохроматической) порошковой дифракции для заданной кристаллической структуры: перечисление отражений, структурный фактор, геометрические и поляризационные множители, нормировка, свёртка пиков с учётом ширины по Кальотти и выбранного профиля линии.

Ниже описан **алгоритм**, реализованный в коде (`src/model/…`), в логическом порядке выполнения.

---

## 1. Общая схема

1. Загружаются параметры ячейки, атомы в асимметричной части и симметрия (номер группы по таблице **International Tables** или вывод из структуры через **spglib**).
2. Строится метрика прямой решётки **G** и сопряжённая **G\***; по симметрии генерируется полный набор атомов в ячейке `full_atoms`.
3. Класс `PowderPattern` задаёт сетку углов \(2\theta\), минимальный межплоскостной отступ \(d_{\min}\) (по умолчанию \(\lambda/2\)), перебирает индексы Миллера \((h,k,l)\), отбрасывает эквивалентные уже учтённые отражения, для каждого пика считает \(d\), угол Брэгга, структурный фактор **F**, кратность **M** (режим `symmetry` или `metric`, §4.4), факторы **L** и **P**, интенсивность \(|F|^2\) с множителями.
4. Интенсивности пиков при необходимости **нормируются** к заданному максимуму; слабые пики отсекаются порогом `intensity_min`.
5. Каждый пик **размазывается** по сетке \(2\theta\) (палочка, Гаусс, Лоренц, псевдо-Фойгт) с полушириной по формуле **Кальотти**; слагаемые суммируются, добавляется **полиномиальный фон** по \(2\theta\).

Точки входа: `main.py` / конфиг OmegaConf, `main_gui.py` для интерактивного режима.

## 2. Решётка и межплоскостное расстояние

### 2.1. Матрица базисных векторов

Параметры ячейки \(a, b, c\) (в ангстремах) и углы \(\alpha, \beta, \gamma\) (в градусах, внутри переводятся в радианы) задают декартовы координаты векторов **a**, **b**, **c** в стандартной ориентации (`Crystal.lattice_to_matrix`):

- **a** \(\parallel\) оси \(x\);
- **b** лежит в плоскости \(xy\);
- **c** достраивается с учётом углов.

### 2.2. Метрические тензоры G и G\*

Метрика **прямой** решётки в кристаллографических (дробных) координатах:

\[
G_{ij} = \mathbf{a}_i \cdot \mathbf{a}_j
\]

(здесь \(\mathbf{a}_1=\mathbf{a}\), \(\mathbf{a}_2=\mathbf{b}\), \(\mathbf{a}_3=\mathbf{c}\); реализация симметрична и совпадает с классическим видом через \(a,b,c\) и косинусы углов).

**Сопряжённая** метрика:

\[
G^* = G^{-1}
\]

Для вектора индексов Миллера \(\mathbf{h}=(h,k,l)^\top\) квадрат обратного межплоскостного расстояния:

\[
\frac{1}{d^2(\mathbf{h})} = \mathbf{h}^\top G^* \mathbf{h}
\]

В коде: `d_spacing` возвращает \(d = 1/\sqrt{\mathbf{h}^\top G^* \mathbf{h}}\) при положительном знаменателе, иначе `inf`.

## 3. Симметрия и атомы в ячейке

### 3.1. Как `Crystal` выбирает симметрию

В `Crystal.__init__` порядок такой:

1. Если передан готовый объект `spacegroup` — он используется как есть.
2. Иначе, если задан целочисленный **`spacegroup_number`** (1…230 по таблице *International Tables for Crystallography*), вызывается `SpaceGroup.from_spacegroup_number(number)`.
3. Иначе, если список `atoms` непустой, вызывается `SpaceGroup.from_structure(lattice, atoms, symprec)` — симметрия **находится автоматически** по геометрии ячейки и наблюдаемым позициям.
4. Если нет ни номера группы, ни атомов — возникает ошибка: без симметрии объект `Crystal` не строится.

Дальше из выбранной группы извлекаются массивы `rotations` и `translations` (каждая операция: целочисленная матрица \(3\times 3\) и вектор сдвига в **дробных** координатах ячейки).

---

### 3.2. Режим по номеру группы: `from_spacegroup_number`

Здесь **поиск симметрии не выполняется** — используется встроенная база **spglib**, согласованная со стандартными настройками пространственных групп.

1. **`spglib.get_spacegroup_type(number)`** по номеру группы (230 шт.) возвращает структуру типа: международное обозначение, Шёнфлиса, **Hall number** и др. Hall-номер однозначно задаёт выбранную *настройку* (origin choice, уникальная форма записи операций) в базе spglib.
2. **`spglib.get_symmetry_from_database(hall_number)`** возвращает полный набор симметрий из базы для этой Hall-настройки: массивы `rotations` и `translations`. Каждая пара \((R, t)\) задаёт операцию в дробных координатах:
   \[
   \mathbf{x}' = R\,\mathbf{x} + \mathbf{t} \pmod 1 \quad\text{(при сведении к ячейке).}
   \]
3. Пары \((R,t)\) упаковываются в список **порождающих** и передаются в `SpaceGroup(generators)`.

В консоль выводятся Hall number, Шёнфлиса и полное международное имя (отладочная печать в коде).

**Важно:** номер группы должен соответствовать той же системе, что и в spglib (стандартные 230 групп). Неверный номер приведёт к неверной симметрии или ошибке библиотеки.

---

### 3.3. Режим «поиск группы по структуре»: `from_structure`

Здесь симметрия **вычисляется** библиотекой spglib по переданной приближённой структуре. Это типичный сценарий, когда в конфиге указано `space_group: null` и заданы только параметры ячейки и атомы.

1. **Ячейка** задаётся матрицей базисных векторов в Ангстрёмах (тот же объект, что строит `Crystal.lattice_to_matrix`): строки матрицы — векторы **a**, **b**, **c** в декартовых координатах.
2. **Позиции** — дробные координаты каждого атома из входного списка `atoms`.
3. **Типы атомов** — целые «атомные номера» для spglib. В коде они берутся из словаря `symbol_to_number` в `space.py` (сопоставление символа элемента, например `"Fe"`, → порядковый номер в таблице Менделеева). Для символа, которого **нет** в словаре, подставляется `0`, что делает автоматический поиск симметрии **ненадёжным** для тяжёлых и экзотических элементов, пока словарь не дополнен.
4. Вызов **`spglib.get_symmetry(cell=(lattice, positions, numbers), symprec=symprec)`**:
   - `symprec` (по умолчанию `1e-5` в `Crystal`) — допуск в Ангстрёмах на совпадение позиций при поиске эквивалентных точек и классификации решётки;
   - spglib находит **пространственную группу**, согласующуюся с переданной решёткой и множеством позиций с учётом периодичности.

На выходе снова получают массивы `rotations` и `translations`, из которых формируются порождающие для `SpaceGroup`.

**Ограничения и смысл алгоритма (на стороне spglib):** это не «угадывание химии», а **геометрическая** классификация: по метрике ячейки и набору точек в ней восстанавливается максимальная симметрия, совместимая с данными в пределах `symprec`. Шум в координатах, неполный набор атомов или ошибка в ячейке могут дать заниженную или неверную группу. Для публикационной точности обычно задают группу явно (`spacegroup_number`).

---

### 3.4. Размножение операций: `generate_space_group`

Список пар \((R, t)\) из базы или из `get_symmetry` может быть набором **порождающих**, а не полного перечня. Класс `SpaceGroup` строит **замыкание** группы в коде (`generate_space_group`):

- Каждая операция — пара \((R, t)\) с целочисленным ортогональным \(R\) (в практике кристаллографии — элементы \(GL(3,\mathbb{Z})\) с сохранением метрики в целочисленной форме).
- **Композиция:** \((R_1,t_1)\circ(R_2,t_2)\) даёт
  \[
  R = R_1 R_2,\quad t = R_1 t_2 + t_1,
  \]
  после чего для сравнения и устранения дубликатов дробная часть \(t\) приводится по компонентам к интервалу \([0,1)\) (если `mod_lattice=False`), либо оставляется как есть (`mod_lattice=True` для «решёточных» операций без свёртки по модулю решётки).
- **Обратная операция:** \(R^{-1}\), \(t' = -R^{-1} t\) с тем же приведением \(t\).
- В множество изначально кладут единицу \((I, 0)\), все порождающие и их обратные, затем в цикле добавляют композиции всех уже найденных пар, пока множество не перестанет расти или не будет превышен лимит **`max_elements`** (в коде 100 — защита от зацикливания при ошибочных данных).

**Канонизация:** перед сравнением операций \(R\) и \(t\) округляются с точностью, связанной с `tol`, и приводятся к кортежам — так отличаются одна и та же операция, записанная с малыми численными шумами.

Итог:

- `operations` — полный список операций со **свёрткой** трансляций по модулю 1 (удобно для эквивалентных позиций в ячейке).
- `lattice_operations` — то же замыкание, но без свёрки `t` по модулю решётки (`mod_lattice=True`), используется в некоторых ветках `apply`.

Свойства `rotations` и `translations` в `SpaceGroup` — это просто списки компонент из `operations`.

---

### 3.5. Применение симметрии к точке: `apply`

Для дробного вектора \(\mathbf{x}\) и списка операций `apply(x, mod_lattice=False)` возвращает список всех образов \(R\mathbf{x}+\mathbf{t}\) для каждой операции из `operations` (или из `lattice_operations`, если `mod_lattice=True`). Именно так для каждого атома асимметричной части получают все кристаллографически эквивалентные позиции.

---

### 3.6. Развёртывание асимметричного набора в `full_atoms`

Входной список `atoms` — это **асимметричная часть** (или эквивалентное минимальное описание): для каждой позиции вызывается `spacegroup.apply`, дубликаты (тот же элемент и совпадающие дробные координаты с точностью `symprec`) отбрасываются. Результат сортируется по элементу и координатам и хранится в `crystal.full_atoms` — **именно он** участвует в расчёте структурного фактора.

## 4. Перечисление отражений и кратность

### 4.1. Ограничение по \(d_{\min}\)

По закону Брэгга \(\sin\theta = \lambda/(2d)\) необходимо \(d \ge \lambda/2\). В коде `d_min = wavelength / 2.0` (по умолчанию).

Верхняя граница индексов оценивается через **минимальное собственное значение** \(G^*\): для всех \(\mathbf{h}\) с \(\|\mathbf{h}^*\|\) порядка \(1/d\) выполняется \(\mathbf{h}^\top G^* \mathbf{h} \le (1/d_{\min})^2\), откуда ограничивают \(\max|h|,|k|,|l|\) (`max_index`).

### 4.2. Исключение дубликатов по орбите

Для фиксированной группы симметрии эквивалентные индексы связаны преобразованием в **сопряжённом** пространстве: если **R** — вращение в прямой решётке, то в индексах используется \((R^{-1})^\top\) (в коде с округлением к целым).

Множество `orbits` накапливает уже обработанные **канонические** тройки `hkl2tuple`. Для нового \((h,k,l)\):

- если тройка уже в `orbits` или это \((0,0,0)\) — пропуск;
- иначе считаются \(d\), \(\theta\), **F**, и по выбранному **режиму кратности** (см. §4.4) получаются множитель **M** и множество эквивалентных **hkl** для слияния пиков; все тройки из этого множества добавляются в `orbits`, чтобы не считать тот же пик повторно.

### 4.3. Кратность **M** и роль в интенсивности

Множитель **M** входит в интенсивность до свёртки (§6.3):

\[
I_{\mathrm{peak}} = \texttt{scale} \cdot M \cdot L \cdot P \cdot |F|^2 .
\]

В физике порошковой дифракции **M** связано с числом кристаллографически эквивалентных отражений, дающих один и тот же конус при случайной ориентации зёрен. В коде **M** и множество «соседних» по учёту индексов **hkl** задаются одной из двух процедур (параметр `multiplicity_mode` в `PowderPattern` и в YAML-конфиге).

Для подписи пика из множества эквивалентных индексов выбирается **представитель** `hkl_name` по детерминированному правилу (предпочтение неотрицательным индексам, меньшей сумме квадратов, тай-брейк через `array_weight`).

---

### 4.4. Режимы расчёта кратности: `symmetry` и `metric`

Выбор режима: поле **`multiplicity_mode`** в конфиге (`symmetry` или `metric`), в GUI — соответствующий переключатель. По умолчанию **`symmetry`**.

Дополнительно для режима **`metric`** задаются **`multiplicity_metric_rtol`** и **`multiplicity_metric_atol`** — относительный и абсолютный допуски при сравнении величин \(1/d^2\) (см. ниже); в коде используется `numpy.isclose` с масштабированием абсолютного допуска относительно \(\max(1/d^2, 1)\).

#### Режим `symmetry` (по умолчанию)

Вызывается **`Crystal.multiplicity(hkl)`**. Для целочисленного \(\mathbf{h}=(h,k,l)^\top\) перебираются все матрицы вращений **R** из симметрии кристалла (`crystal.rotations`, по сути из полной группы `SpaceGroup`). Для каждой **R** в сопряжённом (индексном) пространстве строится образ

\[
\mathbf{h}' = (R^{-1})^\top \mathbf{h},
\]

затем \(\mathbf{h}'\) округляется к ближайшей целочисленной тройке (`hkl2tuple`). Множество **различных** таких троек и есть орбита; **M** = число элементов множества.

Это стандартный кристаллографический способ связать кратность порошкового пика с **точечной** группой / пространственной группой (операции центрирования и пр. уже учтены в наборе операций spglib). Трансляционная часть \((R,\mathbf{t})\) на преобразование индексов **hkl** не влияет — поэтому в цикле участвуют только **R**.

#### Режим `metric` (перебор по \(1/d^2\))

Вызывается **`Crystal.multiplicity_metric(hkl, max_index, rtol, atol)`**. Здесь **не** используются матрицы симметрии для построения орбиты. Вместо этого задаётся та же верхняя граница индексов **`max_index`**, что и в двойном цикле перебора отражений в `PowderPattern._generate_reflections` (оценка из \(d_{\min}\) и спектра \(G^*\)).

Для выбранной тройки \((h,k,l)\) вычисляется

\[
\frac{1}{d^2(\mathbf{h})} = \mathbf{h}^\top G^* \mathbf{h}
\]

(в коде — `invd2_hkl`; совпадает с квадратом длины вектора в метрике обратной решётки).

Далее **полным перебором** просматриваются все целые \((h',k',l')\) с \(|h'|,|k'|,|l'| \le \texttt{max\_index}\), исключая \((0,0,0)\). В множество орбиты попадают те тройки, для которых \(\mathbf{h}'^\top G^* \mathbf{h}'\) совпадает с эталоном в пределах `rtol` / `atol`. **M** = число элементов множества.

**Смысл:** это число **узлов обратной решётки** в заданном кубе индексов, лежащих на одной «сфере» постоянного \(|\mathbf{h}^*|\) (постоянного межплоскостного расстояния \(d\)), **без** использования таблицы симметрии для классификации эквивалентности.

**Ограничения режима `metric`:**

- На одном и том же \(d\) (одинаковом \(1/d^2\)) могут оказаться отражения **не** связанные симметрией кристалла, с **разными** \(|F|\). Код по-прежнему считает **F** только для **одной** тройки \((h,k,l)\), с которой зашли в пик (первая встреченная в порядке перебора), но умножает на **M** из метрического пересчёта. Таким образом, интенсивность в режиме `metric` **не обязана** совпадать с физически корректной порошковой кратностью; возможны **случайные вырождения** по \(d\) и несовпадение с систематическими ослаблениями, которые в режиме `symmetry` отражаются через группу и структурный фактор.
- Режим удобен для сравнения, отладки и учебных экспериментов («сколько целочисленных **hkl** в окне дают тот же \(d\)»).

#### Конфигурация (YAML / OmegaConf)

Пример полей:

```yaml
multiplicity_mode: symmetry   # или metric
multiplicity_metric_rtol: 1.0e-7
multiplicity_metric_atol: 1.0e-12
```

При отсутствии полей в конфиге используются значения по умолчанию в конструкторе `PowderPattern`.

## 5. Угол Брэгга и структурный фактор

### 5.1. Угол дифракции

Для допустимого \(d\):

\[
\theta = \arcsin\left(\frac{\lambda}{2d}\right), \quad 2\theta_{\mathrm{deg}} = 2 \cdot \frac{180^\circ}{\pi}\,\theta .
\]

(\(\theta\) в коде в радианах.)

### 5.2. Величина \(s\)

Используется

\[
s = \frac{\sin\theta}{\lambda}
\]

(величина, пропорциональная модулю вектора рассеяния в подходе \(|\mathbf{k}-\mathbf{k}_0|=4\pi\sin\theta/\lambda\) с обычной кристаллографической нормировкой длины волны в Å).

### 5.3. Формула структурного фактора

Для каждого атома \(j\) в `full_atoms`:

\[
F(\mathbf{h}) = \sum_j n_j\, f_j(s)\, T_j(\mathbf{h})\, \exp\bigl(2\pi i\,\mathbf{h}\cdot \mathbf{r}_j\bigr),
\]

где:

- \(n_j\) — заселённость `occ`;
- \(\mathbf{r}_j\) — дробные координаты `frac`;
- \(T_j\) — тепловой множитель Дебая–Валлера в изотропном приближении:

  \[
  T_j = \exp\bigl(-B_j\, s^2\bigr),
  \]

  `Biso` — параметр \(B\) в Å\(^{-2}\) (как в кристаллографии: связан с среднеквадратичным смещением).

### 5.4. Атомный фактор рассеяния

Вызов из `powder.py` идёт с **`local=True`** (значение по умолчанию в `structure_factor`):

- \(f_j(s)\) берётся из таблицы **Waas–Kirfel** через класс `AtomicScatteringFactor` и файл `data/f0_WaasKirf.dat`: параметризация \(f_0\) для нейтральных атомов/ионов как функция \(s\), с интерполяцией по углу и \(\lambda\) (`get_f0_from_theta_lambda`).

При **`local=False`** (в коде порошка не используется) доступен путь через **xraylib**: рентгеновское \(f_0\) плюс аномальные поправки \(f'\), \(f''\) на заданной энергии \(E = 12.398/\lambda\) кэВ (при \(\lambda\) в Å).

## 6. Интенсивность брэгговского пика (до свёртки)

### 6.1. Лоренц-фактор

Реализовано как для монохроматического пучка на **плоскопараллельной** выборке (классический вид):

\[
L(2\theta) = \frac{1}{\sin^2\theta\,\cos\theta}, \quad \theta = \frac{2\theta}{2}.
\]

Функция `l_factor(twotheta_deg)`.

### 6.2. Поляризационный фактор

Модель **неполяризованного** пучка с углом **монохроматора** \(2\theta_m\) (параметр `thetam_deg` — это как раз \(2\theta_m\) в градусах в формуле кода):

\[
P = \frac{1 + \cos^2(2\theta)\,\cos^2(2\theta_m)}{1 + \cos^2(2\theta_m)}.
\]

При \(2\theta_m = 0\) получается упрощение к виду, близкому к \((1+\cos^2 2\theta)/2\) для неполяризованного случая без монохроматора (согласовано с пределом знаменателя).

### 6.3. Собственно интенсивность

Для каждого уникального отражения (после слияния эквивалентных **hkl** по правилам §4.2–4.4):

\[
I_{\mathrm{peak}} = \texttt{scale} \cdot M \cdot L \cdot P \cdot |F|^2 .
\]

Здесь **M** задаётся режимом **`multiplicity_mode`** (§4.4). Отражения с \(I_{\mathrm{peak}} < \texttt{intensity\_min}\) **не попадают** в список (порог отсечения слабых пиков).

---

## 7. Нормировка интенсивностей

Если `normalize_intensity` истинно, после перечисления всех пиков находится \(I_{\max} = \max I_{\mathrm{peak}}\) и каждая интенсивность заменяется на

\[
I \leftarrow \frac{I}{I_{\max}} \cdot \texttt{intensity\_max\_value}.
\]

В метаданных к пику дописывается пометка «(normalized)» к строке единиц интенсивности.

## 8. Непрерывный порошковый паттерн: ширина и профили

### 8.1. Сетка по \(2\theta\)

`twotheta = np.arange(start, end, step)` — равномерная сетка в градусах.

### 8.2. Полуширина по Кальотти (в радианах Брэгга)

Для угла Брэгга \(\theta\) (в радианах):

\[
\mathrm{FWHM}_\theta = \sqrt{U \tan^2\theta + V \tan\theta + W},
\]

коэффициенты \(U, V, W\) — эмпирические параметры уширения.

В `powder.py` в формулу подставляется угол Брэгга в радианах: \(\theta = (2\theta_{\mathrm{centre}}/2)^\circ \to\) рад (`np.radians(centre / 2)`). Значение `caglioti_fwhm` возвращается в **радианах** и затем переводится в градусы (`np.degrees`). Эта величина передаётся в функции профиля как `fwhm` вместе с центром пика на оси **\(2\theta\)** в градусах (т.е. ширина в коде масштабируется на той же оси, что и сетка паттерна; при необходимости сопоставления с экспериментом в \(2\theta\) может потребоваться явный учёт связи \(\Delta(2\theta)\) с \(\Delta\theta\)).

### 8.3. Профили линий

На сетке \(x = 2\theta\) для центра пика `centre` и параметра ширины `fwhm`, вычисленного на шаге 8.2:

| `profile`   | Поведение |
|---------------|-----------|
| `stick`       | Вся интенсивность в **одном** ближайшем узле сетки. |
| `gaussian`    | Нормированная Гауссиана с \(\sigma = \mathrm{FWHM}/(2\sqrt{2\ln 2})\). |
| `lorentzian`  | Нормированный Коши с \(\gamma = \mathrm{FWHM}/2\). |
| иначе         | **Псевдо-Фойгт**: \(\eta L + (1-\eta) G\), смешивание Лоренца и Гаусса (`eta`). |

Все вклады **суммируются** по пикам: \(y(2\theta) = \sum_i y_i(2\theta)\).

### 8.4. Фон

Добавляется полином второй степени по \(2\theta\):

\[
y_{\mathrm{bg}}(2\theta) = c_0 + c_1\,(2\theta) + c_2\,(2\theta)^2,
\]

коэффициенты `bg_poly` по умолчанию `[0,0,0]` (нулевой фон).

## 10. Допущения и ограничения реализации

1. **Порошок**: ориентационное усреднение зашито в виде кратности **M** и классических **L**, **P**; текстуры и предпочтительная ориентация не моделируются.
2. **Абсорбция**, **микронапряжения**, **размер эффекта частиц** в явном виде не входят в формулу интенсивности (только параметрическое уширение Кальотти).
3. **Аномальная дисперсия** в основном сценарии (`local=True`) **не** добавляется; для учёта \(f', f''\) нужно использовать ветку `local=False` в `structure_factor` (и вызывать её из своего кода).
4. **Перекрытие пиков**: линейное сложение профилей; разделение близких пиков — только суммой кривых.
5. Симметрия и полный список атомов зависят от **корректности** номера группы или автоматического определения spglib; при `from_structure` ограничен словарь `symbol_to_number` (см. §3.3).
6. Режим **`multiplicity_mode: metric`** (§4.4) не гарантирует физически корректную кратность порошка при вырождениях по \(d\) и различных \(|F|\) у «метрически эквивалентных» индексов; для сопоставления с экспериментом предпочтителен **`symmetry`**.
