# XRay_MSU

Расчёт интенсивностей рентгеновской (или монохроматической) порошковой дифракции для заданной кристаллической структуры: перечисление отражений, структурный фактор, геометрические и поляризационные множители, нормировка, свёртка пиков с учётом ширины по Кальотти и выбранного профиля линии.

Ниже описан **алгоритм**, реализованный в коде (`src/model/…`), в логическом порядке выполнения.

---

## 1. Общая схема

1. Загружаются параметры ячейки, атомы в асимметричной части и симметрия (номер группы по таблице **International Tables** или вывод из структуры через **spglib**).
2. Строится метрика прямой решётки **G** и сопряжённая **G\***; по симметрии генерируется полный набор атомов в ячейке `full_atoms`.
3. Класс `PowderPattern` задаёт сетку углов \(2\theta\), минимальный межплоскостной отступ \(d_{\min}\) (по умолчанию \(\lambda/2\)), перебирает индексы Миллера \((h,k,l)\), отбрасывает эквивалентные уже учтённые отражения, для каждого пика считает \(d\), угол Брэгга, структурный фактор **F**, кратность, факторы **L** и **P**, интенсивность \(|F|^2\) с множителями.
4. Интенсивности пиков при необходимости **нормируются** к заданному максимуму; слабые пики отсекаются порогом `intensity_min`.
5. Каждый пик **размазывается** по сетке \(2\theta\) (палочка, Гаусс, Лоренц, псевдо-Фойгт) с полушириной по формуле **Кальотти**; слагаемые суммируются, добавляется **полиномиальный фон** по \(2\theta\).

Точки входа: `main.py` / конфиг OmegaConf, `main_gui.py` для интерактивного режима.

## 2. Решётка и межплоскостное расстояние

### 2.1. Матрица базисных векторов

Параметры ячейки \(a, b, c\) (в ангстремах) и углы \(\alpha, \beta, \gamma\) (в градусах, внутри переводятся в радианы) задают декартовы координаты векторов **a**, **b**, **c** в стандартной ориентации (`Crystal.lattice_to_matrix`):

- **a** \(\parallel\) оси \(x\);
- **b** лежит в плоскости \(xy\);
- **c** достраивается с учётом углов.

### 2.2. Метрические тензоры G и G\*

Метрика **прямой** решётки в кристаллографических (дробных) координатах:

\[
G_{ij} = \mathbf{a}_i \cdot \mathbf{a}_j
\]

(здесь \(\mathbf{a}_1=\mathbf{a}\), \(\mathbf{a}_2=\mathbf{b}\), \(\mathbf{a}_3=\mathbf{c}\); реализация симметрична и совпадает с классическим видом через \(a,b,c\) и косинусы углов).

**Сопряжённая** метрика:

\[
G^* = G^{-1}
\]

Для вектора индексов Миллера \(\mathbf{h}=(h,k,l)^\top\) квадрат обратного межплоскостного расстояния:

\[
\frac{1}{d^2(\mathbf{h})} = \mathbf{h}^\top G^* \mathbf{h}
\]

В коде: `d_spacing` возвращает \(d = 1/\sqrt{\mathbf{h}^\top G^* \mathbf{h}}\) при положительном знаменателе, иначе `inf`.

## 3. Симметрия и атомы в ячейке

### 3.1. Источник симметрии

- Если задан `spacegroup_number`, симметрия загружается из базы **spglib** (`SpaceGroup.from_spacegroup_number`): получают набор матриц вращений **R** и векторов трансляций **t** в дробных координатах.
- Если номер не задан, но есть атомы, можно вызвать `SpaceGroup.from_structure`: симметрия **определяется** по решётке и позициям (с точностью `symprec`).

### 3.2. Развёртывание асимметричного набора

Входной список `atoms` — это **асимметричная часть** (или эквивалентное описание): для каждой позиции применяются все операции группы (`spacegroup.apply`), дубликаты по позиции и элементу отбрасываются. Результат сортируется и хранится в `crystal.full_atoms` — именно он используется в структурном факторе.

## 4. Перечисление отражений и кратность

### 4.1. Ограничение по \(d_{\min}\)

По закону Брэгга \(\sin\theta = \lambda/(2d)\) необходимо \(d \ge \lambda/2\). В коде `d_min = wavelength / 2.0` (по умолчанию).

Верхняя граница индексов оценивается через **минимальное собственное значение** \(G^*\): для всех \(\mathbf{h}\) с \(\|\mathbf{h}^*\|\) порядка \(1/d\) выполняется \(\mathbf{h}^\top G^* \mathbf{h} \le (1/d_{\min})^2\), откуда ограничивают \(\max|h|,|k|,|l|\) (`max_index`).

### 4.2. Исключение дубликатов по орбите

Для фиксированной группы симметрии эквивалентные индексы связаны преобразованием в **сопряжённом** пространстве: если **R** — вращение в прямой решётке, то в индексах используется \((R^{-1})^\top\) (в коде с округлением к целым).

Множество `orbits` накапливает уже обработанные **канонические** тройки `hkl2tuple`. Для нового \((h,k,l)\):

- если тройка уже в `orbits` или это \((0,0,0)\) — пропуск;
- иначе считаются \(d\), \(\theta\), **F**, и из `multiplicity` получается орбита эквивалентных **hkl**; все они добавляются в `orbits`, чтобы не считать тот же пик повторно.

### 4.3. Кратность (мультипликативность)

`multiplicity(hkl)` возвращает число **различных** индексов в орбите точки \(\mathbf{h}\) при действии всех вращений группы (без учёта центрирования как отдельной ветви — оно уже «внутри» набора операций spglib). Это множитель **M** в выражении для интенсивности порошка (число совпадающих по \(d\) и \(\theta\), но разводимых по ориентации зёрен конусов).

Для подписи пика из орбиты выбирается **представитель** `hkl_name` по детерминированному правилу (предпочтение неотрицательным индексам, меньшей сумме квадратов, тай-брейк через `array_weight`).

## 5. Угол Брэгга и структурный фактор

### 5.1. Угол дифракции

Для допустимого \(d\):

\[
\theta = \arcsin\left(\frac{\lambda}{2d}\right), \quad 2\theta_{\mathrm{deg}} = 2 \cdot \frac{180^\circ}{\pi}\,\theta .
\]

(\(\theta\) в коде в радианах.)

### 5.2. Величина \(s\)

Используется

\[
s = \frac{\sin\theta}{\lambda}
\]

(величина, пропорциональная модулю вектора рассеяния в подходе \(|\mathbf{k}-\mathbf{k}_0|=4\pi\sin\theta/\lambda\) с обычной кристаллографической нормировкой длины волны в Å).

### 5.3. Формула структурного фактора

Для каждого атома \(j\) в `full_atoms`:

\[
F(\mathbf{h}) = \sum_j n_j\, f_j(s)\, T_j(\mathbf{h})\, \exp\bigl(2\pi i\,\mathbf{h}\cdot \mathbf{r}_j\bigr),
\]

где:

- \(n_j\) — заселённость `occ`;
- \(\mathbf{r}_j\) — дробные координаты `frac`;
- \(T_j\) — тепловой множитель Дебая–Валлера в изотропном приближении:

  \[
  T_j = \exp\bigl(-B_j\, s^2\bigr),
  \]

  `Biso` — параметр \(B\) в Å\(^{-2}\) (как в кристаллографии: связан с среднеквадратичным смещением).

### 5.4. Атомный фактор рассеяния

Вызов из `powder.py` идёт с **`local=True`** (значение по умолчанию в `structure_factor`):

- \(f_j(s)\) берётся из таблицы **Waas–Kirfel** через класс `AtomicScatteringFactor` и файл `data/f0_WaasKirf.dat`: параметризация \(f_0\) для нейтральных атомов/ионов как функция \(s\), с интерполяцией по углу и \(\lambda\) (`get_f0_from_theta_lambda`).

При **`local=False`** (в коде порошка не используется) доступен путь через **xraylib**: рентгеновское \(f_0\) плюс аномальные поправки \(f'\), \(f''\) на заданной энергии \(E = 12.398/\lambda\) кэВ (при \(\lambda\) в Å).

## 6. Интенсивность брэгговского пика (до свёртки)

### 6.1. Лоренц-фактор

Реализовано как для монохроматического пучка на **плоскопараллельной** выборке (классический вид):

\[
L(2\theta) = \frac{1}{\sin^2\theta\,\cos\theta}, \quad \theta = \frac{2\theta}{2}.
\]

Функция `l_factor(twotheta_deg)`.

### 6.2. Поляризационный фактор

Модель **неполяризованного** пучка с углом **монохроматора** \(2\theta_m\) (параметр `thetam_deg` — это как раз \(2\theta_m\) в градусах в формуле кода):

\[
P = \frac{1 + \cos^2(2\theta)\,\cos^2(2\theta_m)}{1 + \cos^2(2\theta_m)}.
\]

При \(2\theta_m = 0\) получается упрощение к виду, близкому к \((1+\cos^2 2\theta)/2\) для неполяризованного случая без монохроматора (согласовано с пределом знаменателя).

### 6.3. Собственно интенсивность

Для каждого уникального отражения:

\[
I_{\mathrm{peak}} = \texttt{scale} \cdot M \cdot L \cdot P \cdot |F|^2 .
\]

Отражения с \(I_{\mathrm{peak}} < \texttt{intensity\_min}\) **не попадают** в список (порог отсечения слабых пиков).

---

## 7. Нормировка интенсивностей

Если `normalize_intensity` истинно, после перечисления всех пиков находится \(I_{\max} = \max I_{\mathrm{peak}}\) и каждая интенсивность заменяется на

\[
I \leftarrow \frac{I}{I_{\max}} \cdot \texttt{intensity\_max\_value}.
\]

В метаданных к пику дописывается пометка «(normalized)» к строке единиц интенсивности.

## 8. Непрерывный порошковый паттерн: ширина и профили

### 8.1. Сетка по \(2\theta\)

`twotheta = np.arange(start, end, step)` — равномерная сетка в градусах.

### 8.2. Полуширина по Кальотти (в радианах Брэгга)

Для угла Брэгга \(\theta\) (в радианах):

\[
\mathrm{FWHM}_\theta = \sqrt{U \tan^2\theta + V \tan\theta + W},
\]

коэффициенты \(U, V, W\) — эмпирические параметры уширения.

В `powder.py` в формулу подставляется угол Брэгга в радианах: \(\theta = (2\theta_{\mathrm{centre}}/2)^\circ \to\) рад (`np.radians(centre / 2)`). Значение `caglioti_fwhm` возвращается в **радианах** и затем переводится в градусы (`np.degrees`). Эта величина передаётся в функции профиля как `fwhm` вместе с центром пика на оси **\(2\theta\)** в градусах (т.е. ширина в коде масштабируется на той же оси, что и сетка паттерна; при необходимости сопоставления с экспериментом в \(2\theta\) может потребоваться явный учёт связи \(\Delta(2\theta)\) с \(\Delta\theta\)).

### 8.3. Профили линий

На сетке \(x = 2\theta\) для центра пика `centre` и параметра ширины `fwhm`, вычисленного на шаге 8.2:

| `profile`   | Поведение |
|---------------|-----------|
| `stick`       | Вся интенсивность в **одном** ближайшем узле сетки. |
| `gaussian`    | Нормированная Гауссиана с \(\sigma = \mathrm{FWHM}/(2\sqrt{2\ln 2})\). |
| `lorentzian`  | Нормированный Коши с \(\gamma = \mathrm{FWHM}/2\). |
| иначе         | **Псевдо-Фойгт**: \(\eta L + (1-\eta) G\), смешивание Лоренца и Гаусса (`eta`). |

Все вклады **суммируются** по пикам: \(y(2\theta) = \sum_i y_i(2\theta)\).

### 8.4. Фон

Добавляется полином второй степени по \(2\theta\):

\[
y_{\mathrm{bg}}(2\theta) = c_0 + c_1\,(2\theta) + c_2\,(2\theta)^2,
\]

коэффициенты `bg_poly` по умолчанию `[0,0,0]` (нулевой фон).

## 9. Сохранение результатов

При генерации паттерна вызывается `save_refs` (если есть хотя бы одно отражение):

- каталог `runs/<name>/`;
- `<name>.tsv` — таблица с колонками: индексы, \(d\), \(2\theta\), кратность, \(L\), \(P\), \(L\cdot P\), \(F\), интенсивность;
- `G.csv`, `Gstar.csv` — матрицы метрики;
- опционально JSON с отражениями при `save_ref=True`.

Визуализация: `Plot` / matplotlib; в GUI — график `get_pattern_data()` → \(2\theta\), `ycalc`.

## 10. Допущения и ограничения реализации

1. **Порошок**: ориентационное усреднение зашито в виде кратности **M** и классических **L**, **P**; текстуры и предпочтительная ориентация не моделируются.
2. **Абсорбция**, **микронапряжения**, **размер эффекта частиц** в явном виде не входят в формулу интенсивности (только параметрическое уширение Кальотти).
3. **Аномальная дисперсия** в основном сценарии (`local=True`) **не** добавляется; для учёта \(f', f''\) нужно использовать ветку `local=False` в `structure_factor` (и вызывать её из своего кода).
4. **Перекрытие пиков**: линейное сложение профилей; разделение близких пиков — только суммой кривых.
5. Симметрия и полный список атомов зависят от **корректности** номера группы или автоматического определения spglib.
